# Connect

Cloud storage, live databases and REST APIs, browsed in a sidebar and opened like files.

![Connect](../../assets/screenshots/db-sidebar-tree.png)

Each row is one job, with where to find it in the app, on the command line
and as an MCP tool for AI agents. A dash means that surface does not offer it.

| I want to...                                            | In the app                                                                                 | Command line                                                  | MCP tool                                                                                                                                                                                                                                                    |
|---------------------------------------------------------|--------------------------------------------------------------------------------------------|---------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Open files from S3, Azure, GCS, SFTP or WebDAV          | [Cloud Storage](../../usage/cloud-storage.md)                                              | [`--cloud-*`](../../cli/cloud.md)                             | [`list_objects`](../../mcp/tools/list_objects.md), [`copy_object`](../../mcp/tools/copy_object.md), [`move_object`](../../mcp/tools/move_object.md), [`delete_object`](../../mcp/tools/delete_object.md)                                                    |
| Save an open table to the cloud or SFTP                 | [Save an open table](../../usage/cloud-storage.md#save-an-open-table-to-the-cloud-or-sftp) | [`--cloud-put`](../../cli/cloud.md)                           | [`write_table`](../../mcp/tools/write_table.md)                                                                                                                                                                                                             |
| List everything in a bucket                             | [Cloud Inventory](../../usage/cloud-inventory.md)                                          | [`--cloud-*`](../../cli/cloud.md)                             | [`list_objects`](../../mcp/tools/list_objects.md)                                                                                                                                                                                                           |
| Connect to a database                                   | [Database Connections](../../usage/database-connections.md)                                | [`--db-*`](../../cli/databases.md)                            | [`list_db_connections`](../../mcp/tools/list_db_connections.md), [`list_db_tables`](../../mcp/tools/list_db_tables.md)                                                                                                                                      |
| Encrypt a database connection and check its certificate | [Encryption (SSL mode)](../../usage/database-connections.md#encryption-ssl-mode)           | [`sslmode=`](../../cli/cloud.md#managing-connections)         | -                                                                                                                                                                                                                                                           |
