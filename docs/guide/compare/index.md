# Compare and history

Differences between files, versions and servers, and how a table changed over time.

![Compare and history](../../assets/screenshots/compare-view-row-hash.png)

Each row is one job, with where to find it in the app, on the command line
and as an MCP tool for AI agents. A dash means that surface does not offer it.

| I want to...                                         | In the app                                                                            | Command line                                                                                       | MCP tool                                                                                                                   |
|------------------------------------------------------|---------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------|
| Compare two files row by row                         | [Compare View](../../usage/view-modes/compare.md)                                     | [`--diff`](../../cli/diff.md)                                                                      | [`diff_tables`](../../mcp/tools/diff_tables.md)                                                                            |
| Compare two files' columns and types                 | -                                                                                     | [`--compare-schemas`](../../cli/compare-schemas.md)                                                | [`compare_schemas`](../../mcp/tools/compare_schemas.md)                                                                    |
| Compare a file with a database table or cloud object | [Compare with a Database Table or Cloud Object](../../usage/compare-with-database.md) | [`--diff`](../../cli/diff.md)                                                                      | [`diff_tables`](../../mcp/tools/diff_tables.md)                                                                            |
| Compare two or more folders or buckets               | [Compare Folders](../../usage/compare-folders.md)                                     | [`--compare-folders`](../../cli/compare-folders.md)                                                | [`compare_folders`](../../mcp/tools/compare_folders.md)                                                                    |
| Find files whose columns disagree                    | [Schema drift](../../usage/schema-drift.md)                                           | [`--schema-drift`](../../cli/schema-drift.md), [`--validate-schema`](../../cli/validate-schema.md) | [`schema_drift`](../../mcp/tools/schema_drift.md), [`validate_against_schema`](../../mcp/tools/validate_against_schema.md) |
| See how a dataset changed between versions           | [Data Drift](../../usage/data-drift.md)                                               | [`--drift-report`](../../cli/drift-report.md)                                                      | [`data_drift`](../../mcp/tools/data_drift.md)                                                                              |
| Compare two distributions                            | [Compare Distributions](../../usage/compare-distributions.md)                         | [`--compare-distributions`](../../cli/compare-distributions.md)                                    | [`compare_distributions`](../../mcp/tools/compare_distributions.md)                                                        |
| Follow one cell through Git history                  | [Cell history](../../usage/cell-history.md)                                           | [`--cell-history`](../../cli/cell-history.md)                                                      | [`cell_history`](../../mcp/tools/cell_history.md)                                                                          |
| Go back to an earlier version                        | [Earlier Versions](../../usage/earlier-versions.md)                                   | -                                                                                                  | -                                                                                                                          |
