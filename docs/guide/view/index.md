# View and find

Moving around a table, finding rows, highlighting what matters and the other ways to display a file.

![View and find](../../assets/screenshots/hero-table-view.png)

Each row is one job, with where to find it in the app, on the command line
and as an MCP tool for AI agents. A dash means that surface does not offer it.
