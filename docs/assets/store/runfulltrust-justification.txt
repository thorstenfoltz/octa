Octa is a Win32 desktop application packaged as MSIX, with EntryPoint="Windows.FullTrustApplication", so runFullTrust is required by definition. It needs full trust to draw a native OpenGL window, to run its statically linked DuckDB and SQLite engines, and to read the data files the user opens, including companion files such as a Shapefile's .dbf and .shx. It touches only files the user selects, installs no services or drivers, and never requests elevation.
